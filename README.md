# 하네스 엔지니어링: 모델을 에이전트로 만드는 설계

프롬프트, 컨텍스트, 하네스로 에이전트 설계하기

- 온라인으로 읽기: https://seoulkorea-dev.github.io/harness-book/

## 배경

같은 모델을 사용해도 모델 바깥의 하네스, 곧 역할, 도구, 권한, 기록, 검증을 어떻게 설계했는지에 따라 에이전트의 결과가 달라질 수 있습니다. 이 책은 하네스를 정의하고, 하네스로 에이전트를 설계하고, 맡긴 일을 운영하는 방법을 Claude Code와 Codex의 설정과 실습으로 다룹니다.

책은 작가와 에이전트가 함께 만들었고, 그 과정과 기록을 이 저장소에 공개합니다. 작업하며 반복된 실패와 그때 더한 장치, 겪은 어려움과 잘된 점은 마치며에 정리했습니다.

## 구성

시작하며, Chapter 1~10(하네스의 정의와 구성 요소, 에이전트 설계, 프롬프트와 컨텍스트, 착수, 검증, 기록과 인계, 위험 관리, 제품 비교), 마치며, 부록(용어 풀이, 실습, 참고 문헌)

## 작업

- 원고는 `src/`에서 고치고 `python tools/build.py`로 쪽을 만듭니다. 작업 브랜치와 PR로 반영하고, PR마다 자동 검사(`python tools/check_all.py`)를 통과해야 병합합니다.
- 결정은 [DECISIONS.md](DECISIONS.md), 작가가 정할 항목은 [docs/AUTHOR_QUEUE.md](docs/AUTHOR_QUEUE.md), 문서 목록은 [docs/DOCUMENTS.md](docs/DOCUMENTS.md)에 있습니다.
