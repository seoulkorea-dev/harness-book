# 하네스 엔지니어링(가제)

프롬프트, 컨텍스트, 하네스로 AI 에이전트 프로젝트 운영하기

AI 에이전트를 둘러싼 도구, 컨텍스트, 검증, 권한을 설계하는 하네스 엔지니어링을 다루는 책입니다. 현재 집필 단계입니다.

- 온라인: https://seoulkorea-dev.github.io/harness-book/
- 이전 원고(3부 16장 계획, 1장 작성): 태그 `v0-before-reset`

## 폴더 구조

- `src/` 원고 원본과 `site.json`(목차, 쪽 정보)
- `tools/` 빌드(`build.py`), 배포 확인, 유사도 측정, 훅
- `lint/` 자동 검사와 금칙어
- `assets/` 스타일과 Pretendard 글꼴(SIL Open Font License 1.1)
- `reviews/` 검수 기록, `research/` 조사 자료
- `.claude/` Claude Code용 에이전트, 명령, Skill, 훅 설정
- `NEW_BOOK_PLAYBOOK.md`, `RUNBOOK.md`, `BOOK_SPEC.md`, `DECISIONS.md`, `STYLE.md`, `CLAUDE.md` 작업 문서
