# 하네스 엔지니어링: 기초부터 고급까지, 실사용 및 사례 포함

AI 에이전트를 둘러싼 도구, 컨텍스트, 검증, 권한을 설계하는 하네스 엔지니어링을
OpenAI, Anthropic, 제3자의 실제 사례로 배우는 책입니다.

## 온라인으로 읽기

- 표지와 목차: https://seoulkorea-dev.github.io/harness-book/
- 1장 같은 모델, 다른 점수: https://seoulkorea-dev.github.io/harness-book/chapters/ch01.html

## 구성

- 3부 16장 (1부 하네스 개념과 최소 구성, 2부 실무 운영 과제, 3부 규모와 시간 확장)

## 폴더 구조

- `index.html` 표지와 목차
- `chapters/` 장별 원고
- `assets/style.css` 공통 스타일 (아이보리 단일 테마)
- `assets/fonts/` Pretendard v1.3.9 (SIL Open Font License 1.1, `LICENSE.txt` 포함)

## 발표 주체 표시

- O: OpenAI가 발표한 사례
- A: Anthropic이 발표한 사례
- 3: 그 외 기업, 연구자, 개인의 사례 (대상 하네스와 사용 모델 함께 표기)

비교는 회사가 아니라 하네스, 제품, 에이전트 단위로 합니다.
