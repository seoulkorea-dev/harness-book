# Chapter 10 명세

> 플레이북 부록 B 서식(이슈 #118, 2026-10-24 2차 정리). 이전 명세(PR #43의 1, 2차 명세 보강, PR #132의 플레이북 1차 정리)는 git 기록에 있음. 검토 기록: reviews/agents/2026-10-20-ch10-*.md, reviews/agents/2026-10-24-ch10-*.md

- 장 제목: 제품 단위 비교: Codex와 Claude Code의 하네스
- 주장 한 줄(작가 확정, 유지): 제품 선택을 정하는 것은 어느 제품의 모델이 우수한지가 아니라, 조직이 운영하려는 하네스를 각 제품이 어떤 방식으로 구현하는지입니다. (3.2 단정 대비 꼴, 작가 확인 Q-213)
- 이 장을 읽고 할 수 있게 되는 것(세 가지):
  1. 조직의 정책을 규칙 문서, 권한, 격리, 설정 파일의 네 비교 기준으로 나누고, 기준마다 두 제품의 기본 동작과 추가 설정을 구분한다.
  2. 변경 요청 사항의 두 정책(push는 사람만 실행, 외부 자료를 읽지 않음)을 두 제품의 설정으로 각각 작성하고, 금지, 차단, 확인 요청이 어디서 갈리는지 안다.
  3. 설정이 읽혔는지와 금지한 동작이 거부되는지를 제품마다 확인하고, 비교에 쓴 문서의 확인 날짜를 도입 시점의 문서와 대조한다.
