# 그림 8-1, 8-2 명세(8장 개정)

## 그림 8-1
- 예제 사실 없음: 그림, 접근성 설명, 캡션에 CR 사실, 작업 번호, 예제 파일 이름을 넣지 않음(D-116)
- 목적(결론 한 문장): 다음 세션은 대화가 아니라 저장소의 기록으로 이어 갑니다
- 그림이 들어갈 절: kinds
- 형태 후보 두 가지: 1. 흐름형 가로(이전 세션 → 세션 종료 → 다음 세션, 아래 저장소 영역에 남김과 읽음). 2. 구성형(가운데 저장소 영역에 네 기록, 왼쪽 이전 세션이 남기는 것, 오른쪽 다음 세션이 읽는 순서)

### 반드시 보여 줄 것
| 구성 요소 | 한 줄 역할 |
|---|---|
| 이전 세션 | 작업하고 기록을 남김 |
| 세션 종료 | 대화 이력은 다음 세션으로 넘어가지 않음 |
| 다음 세션 | 새 컨텍스트에서 시작 |
| 결정 기록 | 무엇을 왜 정했는지, 결정이 생기면 추가 |
| 진행 기록 | 어디까지 했는지, 작업 단위를 마칠 때 갱신 |
| 규칙 문서 | 모든 작업에 적용할 지침, 시작할 때 자동으로 읽힘 |
| 인계 메모 | 세 기록을 읽도록 묶어 넘기는 문서, 세션 끝에 작성 |

### 반드시 보여 줄 관계
| 시작 | 끝 | 화살표 이름 | 순서 |
|---|---|---|---|
| 이전 세션 | 저장소의 기록 | 남김 | 1 |
| 이전 세션 | 다음 세션 | 대화 이력은 이어지지 않음(회갈 점선, 끊김 표시) | 2 |
| 저장소의 기록 | 다음 세션 | 읽음: 규칙 문서 → 인계 메모 → 결정 기록과 진행 기록 | 3 |

### 맨 아래 "*" 한 줄
- * 세션을 마칠 때 인계 메모를 남기고, 새 세션은 인계 메모가 가리키는 기록을 읽음

### 해설표 행(표 8-1)
| 구성 요소 | 무엇인가 | 본문의 절 |
|---|---|---|
| 세션 종료 | 대화 이력은 새 세션으로 넘어가지 않음 | session |
| 결정 기록, 진행 기록, 규칙 문서 | 기록의 세 종류 | 이 절, decisions |
| 인계 메모 | 세 기록을 새 세션이 읽도록 묶는 문서 | handover |
| 읽는 순서 | 규칙 문서(자동), 인계 메모, 결정 기록과 진행 기록 | handover, example |

## 그림 8-2
- 예제 사실 없음, 제품 기본값(기간 숫자)과 형식 이름(JSONL, OpenTelemetry) 없음. 그것은 해설표 표 8-4가 맡음
- 목적: 하네스는 실행 과정을 자동으로 남기고, 로그가 남아 있어야 완료 보고를 확인할 수 있습니다
- 그림이 들어갈 절: logs
- 형태 후보 두 가지: 1. 구성형 2x2(하네스 영역 안 네 카드 → 아래 사람이 확인). 2. 흐름형(하네스가 남김 → 네 로그 한 줄 → 정할 것 세 가지 → 완료 보고와 함께 확인)

### 반드시 보여 줄 것
| 구성 요소 | 한 줄 역할 |
|---|---|
| 세션 기록 | 메시지, 도구 사용, 결과를 파일로 저장 |
| 실행 결과 | 비용, 토큰 사용량, 턴 수, 세션 ID, 종료 사유 |
| 훅 기록 | 도구 실행 뒤 출력 감사, 압축 전 대화 보관 |
| 조직 지표 | 사용자별 토큰과 비용을 관측 시스템으로 전송(켜야 동작) |
| 정할 것 | 보관 기간, 추적 지점, 확인 방법 |
| 사용자 | 완료 보고를 받을 때 로그를 함께 확인 |

### 반드시 보여 줄 관계
| 시작 | 끝 | 화살표 이름 | 순서 |
|---|---|---|---|
| 하네스 | 네 로그 | 자동으로 남김 | 1 |
| 네 로그 | 사용자 | 완료 보고와 함께 확인 | 2 |

### 맨 아래 "*" 한 줄
- * 보관 기간이 지나면 로그가 삭제되므로 확인할 로그와 기간을 먼저 정함

### 해설표 행(표 8-4)
| 구성 요소 | 무엇인가 | 본문의 절 |
|---|---|---|
| 세션 기록 | 로컬 JSONL 파일, 되감기와 이어 가기에 사용 | 이 절 |
| 실행 결과 | 모든 결과 종류에 비용, 토큰 사용량, 턴 수, 세션 ID | 이 절, Chapter 1 |
| 훅 기록 | PostToolUse, SubagentStart와 SubagentStop, PreCompact | 이 절, Chapter 2 |
| 조직 지표 | OpenTelemetry, 켜야 동작 | 이 절 |
| 보관 기간 | 기본 30일(cleanupPeriodDays) | 이 절 |
