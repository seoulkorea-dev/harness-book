# Chapter 3 명세

- 장 제목: 하네스로 에이전트 설계하기
- 주장 한 줄: 에이전트의 동작은 요청 문장뿐 아니라, 업무의 목적부터 승인 지점까지 하네스에 정의한 아홉 항목에 따라 달라집니다. (ch03-rework 문안 유지, 플레이북 3.2의 관계 서술에 맞음)
- 이 장을 읽고 할 수 있게 되는 것(세 가지):
  1. 맡길 업무 하나에 대해 에이전트 명세서의 아홉 항목(목적, 역할, 입력, 도구, 권한, 기록, 검증, 종료 조건, 승인 지점)에 값을 채울 수 있다.
  2. 에이전트가 수정할 수 있는 파일과 수정할 수 없는 파일을 나누고, 검증 기준(수용 시험, 검사 스크립트)을 수정 금지로 두는 이유와 금지 규칙이 막지 못하는 경로를 말할 수 있다.
  3. 명세서의 값을 규칙 문서, 설정 파일(권한 규칙과 훅), 하위 에이전트 정의의 하네스 설정 파일로 옮기고, 적용되었는지 화면과 검사 출력으로 확인할 수 있다.
