# Chapter 5 명세

- 장 제목: 컨텍스트 엔지니어링: 에이전트가 읽는 정보 설계
- 주장 한 줄: 요청 문장을 다듬는 것만으로는 결과가 정해지지 않고, 에이전트가 판단하는 시점에 어떤 정보를 읽고 있는지에 따라 결과가 달라집니다. (D-126, PR #94. 그대로)
- 이 장을 읽고 할 수 있게 되는 것(세 가지):
  1. 에이전트가 읽는 정보를 네 종류(상시 규칙, 필요할 때 읽는 문서, 작업 입력, 작업 중 수집, 생성 정보)로 나누고, 종류마다 제공 시점과 관리 방식을 정할 수 있다.
  2. 자료를 미리 제공할지 필요할 때 찾게 할지 정하고, 긴 작업에 압축, 구조화된 노트, 하위 에이전트를 쓸 수 있다.
  3. 규칙 문서를 네 기준(구체적으로, 짧게, 일관되게, 나누어서)으로 작성하고, 항목을 추가, 수정, 삭제할 시점과 강제 수단으로 보완할 항목을 판단할 수 있다.
