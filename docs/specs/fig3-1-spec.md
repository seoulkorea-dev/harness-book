# 그림 3-1 명세

- 목적(결론 한 문장): 에이전트는 검증 기준을 수정할 수 없고, 검사를 통과해야 다음 작업 단위로 갑니다.
- 그림이 들어갈 절: 기능 추가 에이전트: CR 구현(id="example"), 대표 그림
- 형태 후보 두 가지(시안 두 개로 그림):
  1. **시안 A: 권한 행렬과 흐름 띠(지금 형태를 다듬은 안).** 위에 행렬(행: 구현 에이전트, 검토 하위 에이전트, 사람(승인자). 열: 수정할 수 있는 파일, 수정할 수 없는 파일). 아래에 작업 단위 하나의 검증 흐름 띠(파일 수정 → 훅의 단위 테스트 → check.py 실행 → 통과 시 commit 확인 → 다음 작업 단위), 실패 분기는 띠 아래 선 위 글자로. 폭 960.
  2. **시안 B: 주체별 가로 줄(스윔레인) 흐름.** 가로 줄 세 개(사람, 구현 에이전트, 검토 하위 에이전트) 위에 작업 단위 하나의 흐름을 2차원으로 그림. 오른쪽 또는 아래에 "수정할 수 없는 파일" 영역(회색 점선)을 두고 구현 에이전트에서 "읽기만" 화살표. 폭 960.

## 쓰지 않을 것
- 본문에 없는 분류, 제품명과 회사명(Claude, .claude는 "설정 폴더"로), 영어 병기, 경고 색(금지는 회색 점선과 "금지" 글자), 상자로 감싼 "그래서 할 일"(맨 아래 "*" 한 줄)
- 그림 안 문구를 "합니다", "으로"로 끝내는 것(결론 제목만 합니다체)
- 접근성 설명(aria-label)과 캡션에도 제품명, 회사명을 쓰지 않음. aria-label은 고른 시안에 맞춰 새로 쓰고, 캡션은 2장 형식("그림 3-1. 제목 (근거)")
