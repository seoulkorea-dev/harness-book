## 그림과 표
- 그림 0-1: 구조는 그대로 두고(시안 생략, HARNESS_SETUP 3장 마지막 줄) 문구만 고침: "도구 도입" → "제품 도입"(부제, 점선 아래 글, 접근성 설명). 캡션 "그림 0-1. 장 묶음의 순서와 제품 도입 경로"(근거 괄호와 "이 책" 삭제, 10.7, 11장)
- 표 0-1: 그림 0-1의 해설표, 개념 정의형 두 열(구성 요소, 주요 역할. 제약이 없어 두 열, 9.2). 이전 "먼저 볼 절" 열은 본문 연계 열이라 빼고(9.1-6), 층위가 다른 "도구 도입 경로" 행은 그림 소개 문단이 맡음(9.3 행 1)
- 이전 둘째 표(장 묶음별 할 수 있게 되는 일)는 해설표와 같은 행을 되풀이하고(9.3-21) 열 이름 "다루는 내용"이 범위가 넓어(9.1-2) 빼고, "읽고 나면 할 수 있는 일"은 장 묶음 목록의 문장으로 옮김
