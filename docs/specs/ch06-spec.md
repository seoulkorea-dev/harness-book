# Chapter 6 명세

- 장 제목(목차 그대로): 착수: 맡길 업무 선정과 작업 단위 분할
- 주장 한 줄(유지): 위임의 성패를 정하는 것은 업무의 크기가 아니라, 업무를 결과를 확인할 수 있는 단위로 나누었는지입니다.
- 할 수 있게 되는 것:
  1. 맡길 업무를 네 기준(결과 확인, 자료 접근, 되돌림, 합의 필요)으로 고르고, 기준을 못 채우는 부분은 사람에게 둔다.
  2. 업무를 한 세션에 끝나고 완료 여부를 확인할 수 있는 작업 단위로 나누고, 목록 파일에 완료 기준, 확인 방법, 통과 값을 적는다.
  3. 서로 독립적인 작업 단위를 하위 에이전트에 나눠 맡기고, 넘길 정보, 결과 확인, 비용 상한을 정한다.
