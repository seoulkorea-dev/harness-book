# 그림 안 "CR" 표기와 그림 2-2 MCP 항목 명세(이슈 #18)

- 규칙(결정 D-114): 그림은 본문 없이 따로 읽힐 수 있으므로, 예제에만 해당하는 사실을 그림에 쓸 때는 "예제"로 밝힌다(예: "CR: commit 확인" → "예제: commit 확인", "(CR 기준)" → "(예제 CR 기준)"). 예제에 해당하지 않거나 장의 요점에 필요 없는 예제 사실은 그림에 넣지 않는다. 그림, 접근성 설명, 캡션에 적용. 본문과 표는 CR을 정의한 뒤 쓰므로 그대로
- 범위: 1~3장 그림(1-1, 1-2, 2-1, 2-2, 3-1)과 캡션. 4장 이후는 각 장 개정 때
