# Chapter 4 명세

- 장 제목(목차 그대로): 프롬프트 엔지니어링: 한 번의 요청 설계
- 주장 한 줄(유지, src/site.json ch04): 결과의 품질을 정하는 것은 문장의 표현이 아니라, 요청에 포함된 목적, 입력, 출력 형식, 완료 기준입니다.
- 할 수 있게 되는 것:
  1. 요청 한 건에 목적, 입력, 출력 형식, 완료 기준이 모두 있는지 점검하고 빠진 요소를 채운다.
  2. 여섯 방법(구체적 지시, 이유 제공, 예시 제공, 구획 구분, 할 일로 지시, 행동 동사)으로 요청 문장을 고친다.
  3. 받은 결과를 완료 기준으로 대조하고, 프롬프트로 해결되지 않는 문제(자료 부족, 반복 작업의 일관성, 결과 검증)를 다음 장의 장치로 넘긴다.
