# Chapter 2 명세(플레이북 정리, 이슈 #110)

- 장 제목: 하네스의 구성 요소
- 주장 한 줄: 에이전트의 결과를 신뢰하려면 도구 연결만으로는 부족하며, 역할, 도구, 권한, 기록, 검증의 다섯 구성 요소를 함께 정의해야 합니다.(작가 확정, 그대로)
- 이 장을 읽고 할 수 있게 되는 것(세 가지):
  1. 하네스의 설정을 다섯 구성 요소로 나누고, 구성 요소마다 무엇을 정하는지와 비었을 때 생기는 실패를 말할 수 있다.
  2. 도구의 가용성(작업 전에 미리 정함)과 권한 평가(호출마다)를 구분해 도구와 권한 규칙을 정할 수 있다.
  3. 규칙마다 지시(규칙 문서)와 강제(권한 규칙, 훅) 가운데 처리 수단을 두 질문으로 정하고, 강제 수단의 적용 범위를 확인할 수 있다.
- 기준: NEW_BOOK_PLAYBOOK.md, BOOK_SPEC.md, 다시 쓴 Chapter 1(PR #103)과 시작하며(PR #108)의 정의와 용어
- 작가 확정(그대로 둠): 도입부(주장 줄, 문단 셋, 요약), 다섯 구성 요소 형식(정의 → 필요한 이유 → 정하는 방법 → 예제에서는), 그림 2-1
