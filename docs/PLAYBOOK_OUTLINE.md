# 플레이북 한 권 정리안(초안)

작가 요청(2026-10-25): 모든 지침, 스킬, 원칙, 규칙을 플레이북 한 권으로 정리한다. 작업 단계(시작, 작성, 검수, 재수정)마다 필요한 내용과 도구를 두고, 전체를 포함하는 원칙과 세부 규칙을 정리한다.

이 문서는 정리안입니다. 작가가 승인하면 NEW_BOOK_PLAYBOOK.md를 이 구성으로 개정합니다(플레이북 부록 D, 부록 E에 기록).

## 1. 정리 원칙

1. **기준 문서는 둘만 둔다.** 모든 책에 같은 플레이북 한 권(NEW_BOOK_PLAYBOOK.md)과 책마다의 설계서(BOOK_SPEC.md). 결정 기록(DECISIONS.md)은 설계서를 바꾸는 작가 결정의 이력이다.
2. **도구는 규칙을 따로 갖지 않는다.** 스킬, 에이전트 정의, 명령, 검사 도구는 플레이북의 어느 장을 실행하는지만 적고, 규칙 본문은 플레이북에만 둔다. 같은 규칙을 두 곳에 쓰지 않는다(대전제 P3).
3. **단계마다 같은 모양으로 쓴다.** 목적 → 입력 → 할 일 → 산출물 → 완료 기준 → 도구 → 따를 세부 규칙(장 번호).
4. **세부 규칙은 사전처럼 한 곳에 둔다.** 작성, 검수, 재수정이 모두 같은 세부 규칙 장을 가리킨다. 검수 기준이 작성 기준과 따로 생기지 않게 한다.
