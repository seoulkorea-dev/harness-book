# 그림(PLAYBOOK 10장)
- 목적: 장의 주장 하나, 결론 한 문장이 제목. 그림은 **일반 내용**(예제 사실, 제품명, 회사명 금지).
- 형태: 구성형(번호 없음), 흐름형(단계에만 번호, 본문과 같게), 비교형. 1장 기준 그림의 부품 체계를 따르고 장마다 새 모양을 만들지 않음. 행과 열은 표로.
- 순서: 결론 한 문장 → 구성 요소와 성격 → 관계(시작, 끝, 이름, 순서) → 구조 검증(글이나 간단한 도식) → 명세(templates/figure-spec.md) → 시안 둘(고른 이유 기록) → SVG로 직접 그리기 → 수치 점검 → 화면 확인 → 캡션, 해설표, 접근성 설명.
- 규격: 단색 면과 선, 그러데이션, 그림자, 아이콘 금지. 강조색 하나, 흑백으로도 구분. 제목 상자, 영역(머리 띠), 항목 카드, 단계 상자, 화살표(주 흐름 실선, 보조 점선), 맨 아래 "*" 한 줄. 폭 760(최소 글자 16px) 또는 960(20px).
- 문구: 제목만 합니다체, 나머지 개조체, "끝" 대신 완료, 주체 명시, 분기 조건을 선 위에, 요약은 상자 없이 "*" 한 줄.
- 본문: 그림 소개는 읽는 순서와 관계를 안내, 그림 읽는 법은 본문에 길게 쓰지 않음.
- 점검: 겹침 0, 최소 글자 기준, 제품명 0, 구성형 번호 0, 제목 단정 0, 데스크톱과 모바일 화면.
