# 독창성(PLAYBOOK 2.1)
- 겹치면 안 되는 것: 장 제목, 부록 이름, 핵심 틀 이름, 주 예제 소재(일치 0).
- 문장 수준: `python tools/similarity_check.py --ab src --gb <비교 도서 경로>` 일치 0.95 이상은 고유 표기 외 0건.
- 비교 도서의 문장, 예제, 표를 참고해 다시 쓰지 않음. 접속이 막혀 측정하지 못하면 작가 확인 목록에 기록.
