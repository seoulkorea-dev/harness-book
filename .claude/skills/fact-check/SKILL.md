# 사실 확인
- 사실은 원문 확인 후에만 넣는다. 확인하지 못하면 넣지 않고 사용자에게 알린다.
- 1차 출처 우선: 발표 기관 원문, 논문, 판결문, 공식 문서. 보도는 1차 출처를 찾는 단서로만.
- 본문 표기: 출처는 문장 안에 주체와 제목으로 밝힌다(배지 쓰지 않음). 수치에는 발표 주체와 시점.
- 제품 기능, 요금, 모델 이름처럼 바뀌는 정보는 "확인 시점"을 남기고 공식 안내 주소를 함께 준다.
- 참고 자료(부록)에는 본문에서 실제로 인용한 문헌만 둔다.
- 기록: research/<장>.md 표(사실, 출처, 주체, 날짜, URL, 확인 문장).
