# 사실과 인용(PLAYBOOK 7, 8장)
- 원문을 확인한 사실만, 확인하지 못하면 쓰지 않고 기록. 조사 기록(research/)에 출처, 확인 날짜, 결과.
- 1차 출처 우선, 명령은 실제 실행. 제품 동작은 한계까지. 발표 주체 밝힘(글을 주어로). 인용은 원문 범위 안.
- 수치는 발표 주체의 값임을 밝힘, 권고와 강제 한도 구분. 바뀌는 정보는 확인 시점, 옛 사례는 버전 주석.
- 원칙, 예제의 선택, 제품의 동작을 섞지 않음. 완료 기준과 근거, 책임 주체, 장치 역할(안내, 기록, 증거, 강제, 승인) 구분.
- 인용 표기: 문장 끝 위첨자, 책 끝 참고 문헌, 같은 자료 같은 번호, 항목 글 자체를 링크, 열람일 없음.
