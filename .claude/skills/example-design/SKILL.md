# 예제(PLAYBOOK 13장)
- 하나의 예제를 책 전체에서 같은 이름으로(정식 첫 등장, 이후 짧은 이름). 예제 사실은 docs/example-facts.md 한 곳.
- 예제 하나에 원리 하나, 예제 위 한 문장으로 원리. 원리 절 뒤 같은 장 예제 절에서 무엇을 정하는지.
- 시작부터 결과까지, 시간 순서 밝힘. 완료 기준과 확인 방법은 내용까지 확인(구현 전 실패, 구현 뒤 통과).
- 다차원(여러 조건, 섞인 정보, 실제 문서 모양). 실행하지 않은 결과는 "예상 결과".
- 계산은 코드로, 날짜는 달력으로 검산. 가상임을 밝힘. 계층 지칭, 연속 과제, 등장인물 금지(설계서 예외만).
- 그림에는 예제를 넣지 않음.
