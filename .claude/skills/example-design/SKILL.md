# 예제 설계
1. 예제 하나에 원리 하나. 그 절이 가르치는 원리를 예제 위 한 문장으로 밝힌다.
2. 본문은 구체 예, 빈칸 템플릿은 부록.
3. 핵심 예제는 결과를 함께 보인다. 실제 실행 결과를 우선한다(examples/에 기록).
4. 같은 소재, 날짜를 여러 장에서 반복하지 않는다.
5. 일반 성인이 바로 이해하는 일상, 업무 소재.
6. 실제 출력이 아니면 "기대 결과 예"라고 밝힌다.
7. 날짜, 수치, 기관은 가상이면 가상임을 밝힌다.
## 실행 기록 형식(examples/<장>-<번호>.md)
날짜, 모델과 제품, 프롬프트 원문, 출력 원문, 재실행 시 차이, 책에 실은 부분
