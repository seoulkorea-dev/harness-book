# 실습(PLAYBOOK 14, 15장)
- 순서: 준비물 → 따라 하기(입력할 곳과 명령) → 실행 결과(실제 출력) → 확인 방법 → 막혔을 때.
- 실행 폴더, 입력할 곳, 파일을 만들 곳, 이미 있을 때, 설치와 로그인, 운영체제 차이를 적음.
- 명령마다 무엇을 하고 무엇이 나오는지 그 자리에. 계속 실행되는 명령은 종료 방법.
- 확인 화면이 나올 때의 판단 기준, 실패할 때와 되돌리기.
- 실제로 실행해 확인한 것만 실행 결과로. 실행 기록이 없으면 "실행 기록 확인 전의 예상".
- 코드와 설정은 각 부분의 뜻을 풀고, 발췌는 발췌임과 더할 위치를 밝힘.
- 참고본은 설정으로 읽히지 않게 이름에 표시(.example).
