# 표(PLAYBOOK 9, 11장)
- 열: 명사형, 2~4개, 모호한 열(설명, 내용, 방법, 기준, 이유) 금지, 동사형, 질문형 금지, 본문 연계 열("관련 절") 금지, 지시 표현 금지.
- 표준 세트에서 고름: 개념 정의형(구성 요소, 주요 역할, 기능적 제약), 주체 구분형, 보완 관계형, 예제 적용(구분, 결정 사항, 운영 기준, 설정 이유), 실패 표(실패 유형, 원인, 방지 장치), 확인 표(확인 항목, 확인 방법, 확인 기준), 비교 표, 진단 표. 없으면 세트를 먼저 추가.
- 세트가 맞지 않는 짧은 대조나 정리는 간단한 표(열 2~3개, 행 2~5개, 9.1 열 규칙 유지, 실패 표와 확인 표와 그림 해설표 대신 쓰지 않음, 두 장 이상 쓰이면 세트로 올림, 플레이북 9.2).
- 행: 같은 질문의 답, 한 행 한 항목, 같은 방향의 명사, 같은 열의 분류 수준 일치, 의미 있는 순서, 3~7행, 장 사이 같은 행 이름.
- 칸: 한 칸 한 내용, 명사형과 마침표 없음, 행마다 구체적, 이유 칸은 한 관점, 근거 없는 수치 금지, 본문과 같은 용어, 칸 안 병기와 링크 금지, 번호 목록은 열로.
- 표 전체: 두 기준 섞지 않기, 같은 정보의 표 두 번 금지, 캡션의 개수와 행 수 일치, 고칠 때 열 구성 유지.
- 표 앞 문장이 읽는 법을 알림, 표의 이름이 본문보다 먼저 나오지 않음.
- 캡션: "표 N-n. 제목", 근거 괄호 없음, 설명 줄은 결론이 있을 때만.
- 검수 때 표 점검 표: | 표 번호 | 쓴 세트 | 열 이름 | 판정 |
