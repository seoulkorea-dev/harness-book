# 한국어 기술서 문체
## 문장
- 본문은 합니다체. 항목 나열은 가운뎃점 대신 쉼표.
- 절 첫 문장은 정의나 결론(두괄식). 설명 문단은 귀결식 허용.
- 추측 표현("것 같습니다", "대체로")과 lint/banned.txt의 금칙어는 쓰지 않는다.
## 어휘 치환표(B 등급, 경고)
| 쓰지 않음 | 쓴다 |
|---|---|
| 넣다 | 입력(데이터), 포함(요소, 예시), 저장(저장소) |
| 바꾸다 | 변환(형태), 변경(설정, 내용) |
| 고르다 | 선택 |
| 쓰다 | 사용, 작성 |
| 붙이다 | 첨부, 추가(덧붙이다는 허용) |
| 틀리다 | 오류가 있다 |
| 고치다 | 수정 |
| 끄다 | 해제 |
예외: 인용문, 일부러 보인 나쁜 예(개선 전 프롬프트), 고유명사, 법령 조문, 굳은 말(붙여 넣다, 고르지 않다, 읽기와 쓰기 권한).
## 영문 병기
- 각 Chapter에서 용어 사전 표제어가 처음 나올 때만 `한글(원어)` 또는 `한글(원어, 약어)`. 괄호는 한글에 붙인다.
- 원어는 각 단어 첫 글자 대문자, 둘째 단어 이후 관사, 전치사, 접속사와 하이픈 뒤는 소문자. 예: 단계별 추론(Chain of Thought, CoT)
- 표 셀, 캡션, 제목, 코드 상자에는 병기하지 않는다.
## 독자와 예제
- 책의 독자(수준)는 본문에 쓰지 않는다. 결과물을 읽을 사람은 "읽을 사람".
- 예제에 학년, 직업, 계층을 지칭하지 않는다. 예외: 속성 비교가 방법인 예제(편향 점검).
## 프롬프트 예제
- 말투는 반말 요청체("~해 줘", "~하지 마"). 개선 전과 개선 후의 말투를 같게.
- 구성 요소를 보여 주는 예제는 [목적] [역할] [맥락] [출력 형식] [제약 조건] 이름표를 이 순서로, 필요 없는 요소는 생략.
## 캡션
- 표와 그림: 번호, 제목, 설명 1줄(명사로 끝맺음).
