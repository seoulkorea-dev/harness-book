# 문장과 어휘(PLAYBOOK 6장, 7.2)
- 한 문장 한 정보, 150자를 넘으면 나누기 검토. 주어와 서술어 호응, 주체 밝히기, 모호한 지시어 대신 대상.
- 정의, 조건, 주체, 예외는 줄이면서도 빼지 않음. 짧게 줄이다 주어가 빠지지 않게.
- 합니다체, 쉬운 말, 비유 금지, 독자 지칭 금지, 의도 표현 금지, 관찰자 표현 금지, 질문형 문장은 절 첫 문장에 하나만(장 도입부 금지, 점검 질문 절 제외, 플레이북 6.2).
- **"이 책" 표현은 시작하며에서 책을 처음 안내할 때만.** 본문은 3자 관점으로 설명만.
- 작업 이력, 검수 설명문을 원고에 넣지 않음.
- 어휘 절차: 뜻 확정 → 후보 수집 → 표준어 → 용례 → 위치 규칙(셀, 소제목, 캡션은 명사형, 본문은 한자어 명사 셋 연속 금지) → 배제어.
- 배제어: 구어 부사, 비유성 동사, 평가 수식어, 누락의 구어 표현, 관공서체 한자어, 군더더기 보조용언, 추측 표현.
- 치환: 넣다 → 입력, 포함 / 바꾸다 → 변경 / 고르다 → 선택 / 쓰다 → 사용, 작성 / 고치다 → 수정 / 끄다 → 해제, 종료.
- 단정("반드시", "막는다", "항상")은 조건과 근거가 있을 때만. 원칙, 권장, 예외 구분. 같은 장치의 힘을 같은 정도로.
- 나열은 쉼표, 가운뎃점과 빗금과 강조 따옴표 금지.
