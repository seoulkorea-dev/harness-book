# 장 검토(PLAYBOOK 20, 21, 25장)
- 판정 순서: 독자 이해 → 흐름 → 정의와 용어 → 일관성 → 사실 → 형식. 앞이 해결되지 않으면 통과시키지 않음.
- 장 전체 통독, 세 관점(실무자, 편집자, 독자), 고칠 문장 비율, 절별 내용 정리표, 표 점검 표.
- "끊김 0" 판정에는 근거. 원고 판정과 기록 점검을 나눔. 지적마다 근거 원칙.
- 등급: 필수 수정(통과 불가), 편집 권고, 검증 후 확정.
- 검토는 1회. 검토 제안도 플레이북에 대조한 뒤 냄.
- 반영 확인 체크리스트 11개(21장), 최종 점검표 전 문항(25장).
