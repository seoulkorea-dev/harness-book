# 장과 절의 구조(PLAYBOOK 3, 4, 12장)
- 장 틀: 주장 줄 → 도입부 → 원리 절 → 예제 절 → 실패를 예방하는 장치 → 설정과 결과의 확인 방법 → 설계 원칙과 점검 질문. 예외는 설계서에.
- 주장 줄: 한 문장, "A가 아니라 B" 금지, 원칙 문장과 같은 뜻이되 같은 문장 아님.
- 도입부: "이 장에서는 …을 다룹니다"와 왜 → 전체 틀 → 장의 순서 → 요약. 정의 전 용어 금지, 같은 공식 반복 금지.
- 절 제목: 목적, 원리, 한계가 드러나게, 대상 밝히기, 본문 용어와 같게, 문서투 금지.
- 절 전개: 왜 → 무엇 → 어떻게 → 근거. 정의만 있는 곳에 이유. 핵심 정의와 쉬운 예는 앞에.
- 여러 항목 절: "이름: 한 줄 정의" + 같은 모양의 하위 항목(완전한 문장).
- 연결: 넘어오는 이유, 지시어 대상 확인, 약속은 그 자리에서, 끼워 넣기 뒤 앞뒤 정독. 흐름 유형(연결 끊김, 중복, 위치 어긋남, 맥락 없음, 건너뛴 단계, 오기) 0.
- 링크: 꼭 필요할 때만, 그 장에서 먼저 설명, 내용이 있는 절로, 같은 장 링크 금지, 가리키기만 하는 문장 금지.
