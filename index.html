이 책의 독자

이 책은 프롬프트를 쓸 줄 알고 AI 생태계를 어느 정도 아는 독자를 위한 책입니다. LLM이 무엇인지, 프롬프트를 어떻게 쓰는지는 설명하지 않습니다. 대신 에이전트가 실제 일을 할 때 결과를 좌우하는 바깥 구조, 곧 하네스를 다룹니다.

초급은 하네스라는 개념과 최소 구성을 익히는 단계, 중급은 실무 운영에서 부딪히는 검증, 컨텍스트, 권한 문제를 다루는 단계, 상급은 여러 에이전트와 긴 작업, 평가, 조직 도입으로 규모를 키우는 단계입니다.

읽는 법

모든 장은 사례로 시작합니다. 그리고 다음 순서로 진행합니다.

  1. 사례: 누가, 무엇을 하다가, 어떤 일이 있었나
  2. 문제 분석: 모델 문제인가, 하네스 문제인가
  3. 하네스 해법: 그들이 실제로 바꾼 것
  4. 내 프로젝트 적용: 바로 해볼 것
  5. 체크리스트

사례와 인용에는 출처를 반드시 표시합니다. 같은 개념이라도 OpenAI와 Anthropic은 다른 방식으로 풀기 때문입니다.

제3자

두 회사가 아닌 기업, 연구자, 개인의 사례. 어떤 회사의 모델을 썼는지 함께 적습니다.

책에 나오는 수치는 모두 해당 회사나 저자가 스스로 발표한 값이며, 독립적으로 검증된 값이 아닙니다.

1부 초급: 하네스가 결과를 바꾼다

  1. 1장같은 모델, 다른 점수제3자 LangChain이 모델을 고정하고 하네스만 바꿔 점수를 올린 실험, Anthropic의 SWE-bench 최소 스캐폴드원고
  2. 2장실수를 환경에 새긴다제3자 Mitchell Hashimoto가 이름 붙인 습관과 용어의 확산준비 중
  3. 3장에이전트가 못 보면 없는 것이다OpenAI의 저장소 컨텍스트 교훈, AGENTS.md와 Claude Code 지시 파일준비 중
  4. 4장도구 설명 한 줄이 행동을 바꾼다Anthropic SWE-bench 에이전트의 도구 설계 반복준비 중
  5. 5장최소 하네스 재현하기Anthropic의 프롬프트, bash, 편집 도구 구성을 직접 재현준비 중

2부 중급: 운영에서 부딪히는 문제들

  1. 6장두 하네스 해부: Codex와 Claude CodeOpenAI와 Anthropic 도구의 확장 지점 비교준비 중
  2. 7장말로 부탁하지 말고 기계로 강제하라OpenAI의 린터, CI, 브라우저 연동과 Anthropic의 증거 요구 훅준비 중
  3. 8장컨텍스트가 곧 비용이다제3자 Manus의 캐시 설계와 파일 기반 기억, OpenAI의 대화 압축준비 중
  4. 9장사고 두 건으로 배우는 권한 설계제3자 Replit 운영 DB 삭제, Amazon Q 삭제 지시 프롬프트 배포준비 중
  5. 10장100만 줄 실험 따라가기OpenAI 팀의 5개월 에이전트 중심 개발준비 중
  6. 11장완료 보고를 믿지 않는 관리법제3자 Replit의 거짓 보고, OpenAI의 품질 부채 정리준비 중

3부 상급: 규모와 시간을 늘릴 때

  1. 12장멀티 에이전트, 언제 이기고 언제 지나Anthropic 리서치 시스템과 16개 에이전트 C 컴파일러준비 중
  2. 13장교대 근무하는 에이전트Anthropic 장시간 에이전트의 초기화, 코딩 에이전트 분리준비 중
  3. 14장하네스 개선을 수치로 증명하기Anthropic BrowseComp 분석과 LLM 채점, 제3자 LangChain 재분석준비 중
  4. 15장규제 산업에 들여올 때OpenAI 사례에 대한 데이터 주권 비판과 감사, 책임 설계준비 중
  5. 16장배가 될 것인가, 기둥이 될 것인가제3자 Manus, OpenAI, Anthropic이 보는 하네스의 미래준비 중
