대상 독자

이 책은 AI 에이전트를 처음 공부하는 독자를 위한 책입니다. 1장에서 AI 모델, 에이전트, 하네스의 기초 개념을 설명하고, 2장부터 하네스의 구성 요소를 하나씩 다룹니다. 모든 장은 실제 사례를 바탕으로 설명합니다.

1부 하네스 개념과 최소 구성

  1. 1장같은 모델, 다른 점수AI 모델, 에이전트, 하네스의 기초 개념. LangChain이 모델을 고정하고 하네스만 바꿔 점수를 올린 실험, Anthropic의 SWE-bench 최소 스캐폴드원고
  2. 2장실수의 환경 각인Mitchell Hashimoto가 이름 붙인 습관과 용어의 확산준비 중
  3. 3장에이전트 가시 범위와 저장소 컨텍스트OpenAI의 저장소 컨텍스트 교훈, AGENTS.md와 Claude Code 지시 파일준비 중
  4. 4장도구 설명과 에이전트 행동Anthropic SWE-bench 에이전트의 도구 설계 반복준비 중
  5. 5장최소 하네스 재현Anthropic의 프롬프트, bash, 편집 도구 구성을 직접 재현준비 중

2부 실무 운영 과제

  1. 6장두 하네스 해부: Codex, Claude CodeCodex와 Claude Code의 확장 지점 비교준비 중
  2. 7장지시 대신 기계적 강제OpenAI의 린터, CI, 브라우저 연동과 Anthropic의 증거 요구 훅준비 중
  3. 8장컨텍스트와 비용Manus의 캐시 설계와 파일 기반 기억, OpenAI의 대화 압축준비 중
  4. 9장사고 사례 두 건과 권한 설계Replit 운영 DB 삭제, Amazon Q 삭제 지시 프롬프트 배포준비 중
  5. 10장100만 줄 실험 분석OpenAI 팀의 5개월 에이전트 중심 개발준비 중
  6. 11장완료 보고 검증 관리Replit의 거짓 보고, OpenAI의 품질 부채 정리준비 중

3부 규모와 시간 확장

  1. 12장멀티 에이전트 성패 조건Anthropic 리서치 시스템과 16개 에이전트 C 컴파일러준비 중
  2. 13장에이전트 교대 근무Anthropic 장시간 에이전트의 초기화, 코딩 에이전트 분리준비 중
  3. 14장하네스 개선 효과 정량 검증Anthropic BrowseComp 분석과 LLM 채점, LangChain 재분석준비 중
  4. 15장규제 산업 도입OpenAI 사례에 대한 데이터 주권 비판과 감사, 책임 설계준비 중
  5. 16장하네스 미래 전망Manus, OpenAI, Anthropic이 보는 하네스의 미래준비 중
