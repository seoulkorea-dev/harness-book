부록

실습

본문에서 설명한 하네스를 직접 구성하고 실행해 보는 실습을 모았습니다. 실습은 경비 정산 미니 웹 앱 하나를 함께 사용합니다.

실습 준비

이 책의 실습은 경비 정산 미니 웹 앱 하나를 책 전체에서 함께 사용합니다. 실습 자료는 저장소의 examples/expense-app/ 폴더에 둡니다. 실습에는 세 가지 도구가 필요합니다.

  • Python 3: 미니 웹 앱과 테스트를 실행합니다. 실습 코드는 표준 라이브러리만 사용하므로 추가 패키지를 설치하지 않습니다.
  • Git: 실습 저장소를 내려받고 변경 이력을 확인합니다.
  • Claude Code: 실습에서 에이전트를 실행합니다. Claude Code는 Pro 이상의 유료 요금제나 Claude Console의 API 키로 사용하며, 무료 요금제에는 포함되지 않습니다(Anthropic, 2026).

Windows에서는 PowerShell에서 다음 명령으로 Claude Code를 설치합니다. macOS와 Linux의 설치 명령은 Claude Code 공식 문서를 따릅니다.

irm https://claude.ai/install.ps1 | iex

Windows에서 Git for Windows를 설치하면 Claude Code는 셸 명령을 Git Bash로 실행합니다. 설치하지 않으면 PowerShell로 실행합니다(Anthropic, 2026).

설치를 마친 뒤 터미널에서 다음 세 명령으로 도구를 확인합니다.

python --version
git --version
claude --version

세 명령이 모두 버전 번호를 출력하면 실습을 시작할 수 있습니다. macOS와 Linux에서 python 명령을 찾지 못하면 python3 명령을 사용합니다.

버전 주석 (2026년 10월) 요금제와 설치 방법은 2026년 10월에 확인한 공식 문서 기준입니다. 도입 시점의 문서에서 다시 확인합니다.

각 실습의 실행 결과는 실행한 뒤 이 쪽과 저장소의 examples/expense-app/RUNLOG.md에 기록합니다.

실습 1. 실습 저장소와 기준 상태

실습 저장소를 내려받고, 경비 정산 시스템 개편 변경 요청(Change Request) CR을 구현하기 전의 기준 상태를 확인합니다. 관련 내용은 Chapter 3에 있습니다.

준비물

  • 실습 준비의 세 도구

따라 하기

터미널에서 다음 명령을 차례로 실행합니다.

git clone https://github.com/seoulkorea-dev/harness-book.git
cd harness-book/examples/expense-app
python -m unittest discover tests -q
python check.py
python app.py

마지막 명령은 앱을 실행합니다. 브라우저에서 http://localhost:8000을 열어 정산 요청 목록을 확인하고, 터미널에서 Ctrl+C를 눌러 종료합니다.

확인 방법

  • 단위 테스트 명령의 마지막 줄이 OK입니다.
  • check.py는 tests 3건이 모두 통과하고, acceptance 5건 가운데 3건이 실패하며 종료 코드 1로 끝납니다. CR을 구현하기 전이므로 정상입니다.
  • 이 폴더에는 아직 CLAUDE.md와 .claude/ 폴더가 없습니다. 하네스는 실습 2~5에서 만듭니다.

실습 2. 규칙 문서 작성

에이전트가 세션마다 읽을 규칙 문서 CLAUDE.md를 작성합니다. 관련 내용은 Chapter 5에 있습니다.

준비물

  • 실습 1을 마친 examples/expense-app/ 폴더
  • 텍스트 편집기

따라 하기

  1. examples/expense-app/에 CLAUDE.md 파일을 만듭니다.
  2. 목적, 읽는 순서, 작업 순서, 수정 범위, 중단 규칙, 명령의 여섯 절을 작성합니다. 수정 범위에는 data/, acceptance/, check.py, CLAUDE.md, DECISIONS.md, .claude/를 수정하지 않는다고 적습니다.
  3. 작성한 파일을 reference/CLAUDE.example.md와 비교해 누락된 항목을 채웁니다.
  4. 같은 폴더에서 claude 명령으로 Claude Code를 시작하고, 다음 요청을 입력합니다.
이 저장소에서 수정하면 안 되는 파일과 폴더를 알려 줘.

확인 방법

  • 응답이 CLAUDE.md의 수정 범위(data/, acceptance/, check.py 등)를 그대로 따르는지 확인합니다.
  • 규칙 문서는 지시이므로, 이 단계에서는 수정 시도를 막지 못합니다. 막는 장치는 실습 3에서 만듭니다.

실습 3. 권한 설정

되돌리기 어려운 동작을 권한 규칙으로 막고, commit에는 확인을 거치게 합니다. 관련 내용은 Chapter 9에 있습니다.

준비물

  • 실습 2를 마친 폴더

따라 하기

  1. examples/expense-app/ 아래에 .claude 폴더를 만들고, 그 안에 settings.json을 만듭니다.
  2. reference/settings.example.json의 permissions 부분을 옮깁니다. hooks 부분은 실습 4에서 추가합니다.
  3. Claude Code를 다시 시작하고 /permissions를 입력해 규칙이 읽혔는지 확인합니다.
  4. 다음 두 요청을 차례로 입력합니다.
data/projects.csv에 PRJ-2604 행을 추가해 줘.
원격 저장소에 push해 줘.

확인 방법

  • /permissions 화면에 allow, ask, deny 규칙이 보입니다.
  • 두 요청 모두 실행되지 않고 거부됩니다. 거부 메시지를 실행 기록에 남깁니다.
  • data/projects.csv가 변경되지 않았는지 git status로 확인합니다.

실습 4. 검증 장치

편집할 때마다 단위 테스트를 자동으로 실행하는 훅과, 수용 기준을 대조하는 검토 하위 에이전트를 만듭니다. 관련 내용은 Chapter 7에 있습니다.

준비물

  • 실습 3을 마친 폴더

따라 하기

  1. .claude/settings.json에 reference/settings.example.json의 hooks 부분을 추가합니다.
  2. .claude 폴더 아래에 agents 폴더를 만들고, reference/reviewer.example.md를 reviewer.md라는 이름으로 복사합니다.
  3. Claude Code를 다시 시작하고 다음 요청을 차례로 입력합니다.
expense/views.py의 목록 제목을 "정산 요청 목록(시험)"으로 수정해 줘.
방금 수정한 내용을 되돌려 줘.
reviewer 에이전트로 현재 코드가 docs/CR.md의 수용 기준을 충족하는지 확인해 줘.

확인 방법

  • 파일을 수정한 뒤 단위 테스트가 자동으로 실행된 흔적이 대화에 보입니다.
  • reviewer 보고가 수용 기준마다 충족, 미충족, 확인 불가를 근거 파일과 함께 제시합니다. CR을 구현하기 전이므로 기준 1~3은 미충족입니다.

실습 5. 작업 단위로 구현

작업 단위 목록을 만들고, 첫 세션에서 작업 단위를 하나씩 구현합니다. 관련 내용은 Chapter 6에 있습니다.

준비물

  • 실습 4를 마친 폴더

따라 하기

  1. reference/tasks.example.json을 examples/expense-app/tasks.json으로 복사합니다.
  2. Claude Code를 다시 시작하고 다음 요청을 입력합니다.
CLAUDE.md의 규칙대로 tasks.json의 다음 작업 단위를 수행해 줘.

commit 확인 요청이 나오면 변경 내용을 읽고 승인합니다. 에이전트가 작업 2를 마치면 같은 요청으로 작업 3을 이어서 맡깁니다.

확인 방법

  • 완료 보고에 python check.py의 출력 원문이 들어 있습니다.
  • tasks.json에서 마친 작업 단위의 통과 값만 true로 변경되었습니다.
  • git log로 작업 단위마다 commit이 하나씩 있는지 확인합니다.

실습 6. 기록과 인계

첫 세션을 인계 메모로 마치고, 새 세션이 인계 메모만으로 작업을 이어 가는지 확인합니다. 관련 내용은 Chapter 8에 있습니다.

준비물

  • 실습 5를 마친 세션

따라 하기

  1. 첫 세션에서 다음 요청을 입력하고, 작성된 HANDOFF.md를 확인한 뒤 /exit로 종료합니다.
세션을 마치려고 해. CLAUDE.md의 항목대로 HANDOFF.md를 작성해 줘.
  1. claude 명령으로 새 세션을 시작하고 다음 요청을 입력합니다.
HANDOFF.md를 읽고 이어서 작업해 줘.
  1. 작업 4가 끝나면 python app.py로 등록 화면에서 프로젝트 코드를 선택할 수 있는지 확인합니다.

확인 방법

  • 새 세션이 이전 대화 없이 HANDOFF.md와 tasks.json만으로 다음 작업 단위를 선택합니다.
  • python check.py가 종료 코드 0으로 끝나면 CR의 수용 기준을 모두 충족한 것입니다.
  • 통합 테스트 시나리오(작업 5)는 에이전트가 초안을 작성하고, 승인 여부는 직접 판단합니다.
