# Chapter 11 editor 명세 검토(2026-10-20, PR #44)


대상은 docs/specs/ch11-spec.md와 docs/specs/fig11-spec.md입니다. 파일은 고치지 않았습니다. 형식은 발견 | 위치 | 근거 | 제안 | 확신입니다.

판정: **보강 필요** (필수 9, 권장 10, 작가 확인 3)

요약: 장 흐름표와 절 첫 문단 계획의 골격(왜 → 무엇 → 어떻게 → 근거, 앞 장 용어 상기, 앵커 유지)은 7~10장 선례를 잘 따랐습니다. 막히는 곳은 네 가지입니다.
- 이 책의 사례 서술("처음부터")이 저장소 사실과 어긋납니다.
- 표 11-3과 표 11-5가 FAILURES.md, DECISIONS.md의 실제 상태와 맞지 않습니다.
- 개정 전 점검의 필수 항목 일부가 흡수되지 않았습니다.
- 그림 11-1 명세의 구성 요소 분류와 해설표가 어긋납니다.

저장소와 직접 대조해 확인한 사실은 맞습니다.
- 에이전트 정의는 8개(.claude/agents), 명령 정의는 7개(.claude/commands)입니다.
- 훅은 네 종류입니다(.claude/settings.json의 SessionStart, PreToolUse, PostToolUse, Stop).
- check.yml은 branches: [main]에 트리거되고, verify-site.yml은 page_build와 workflow_dispatch에 트리거됩니다.
- FAILURES.md의 F-06, F-16, F-17, F-18 행과 원인 구성 요소는 spec 61행과 일치합니다.
- D-099~D-118의 대체 열이 비어 있다는 S-C11-4의 지적도 맞습니다(D-099, D-100, D-101, D-107, D-110).
