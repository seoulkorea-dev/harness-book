# ch04 점검 의견 처리(2026-10-20)
점검: fact-checker(필수 0), flow-reviewer(필수 0), figure-checker(필수 3), reader-novice(읽기 중단 0). alt-reviewer는 시안 단계에서 같은 그림을 보아 다시 부르지 않음(비용 규칙).

| 의견 | 출처(심각도) | 처리 |
|---|---|---|
| 그림 4-1 "요청자"가 본문에 없음 | figure(필수), flow | 반영: 그림과 본문을 "요청하는 사람"으로 통일 |
| "결과 대조" 글자 겹침, 모델의 결과 상자 여백 | figure(필수, 권장) | 반영: 글자를 화살표 위로, 상자 폭 넓힘 |
| 그림 해설표 없음 | figure(필수) | 반영: 표 4-2 "그림 4-1의 구성 요소" 신설, 뒤 표 번호 하나씩 미룸(조사 포함). 그림 4-2는 요점이 본문 techniques 목록과 같아 목록이 해설(2장 그림 2-1과 같은 처리), editor 판단 |
| limits 링크, 연동 규격 사례 한정, 그림 4-2 범위 | fact(권장) | 반영: 링크 두 곳, "실시간 연동 규격", 사례 문장과 D-012 연결, 캡션 "(프롬프트 작성 문서에서 선별한 여섯 가지)" |
| "이 요청은" 대상, 공수 첫 등장, 표 4-4 범위, 추측과 기대의 관계, 참조 순서, 용어 | flow(권장) | 반영 |
| 누락 요소 이름, CR 표지, 코드 출처, 완료 기준의 뜻, 대조 절차, 예시 수, 구획 구분 이유 | novice(권장) | 반영(할 일로 지시의 이유는 research에 근거가 없어 보류) |
| "번호나 글머리표로" 조사, 낱말 차이, 목적 카드 문구, 빈 text | figure(권장, 참고) | 반영 |
| 그림 4-2 보조 형태 부족 | figure(권장) | 보류(본문에 없는 분류를 더하지 않음, editor 판단) |
| 기타 참고(읽기 방향, 단계 상자 테두리, 주장 반복, 결과 화면 등) | figure, flow, novice | 보류 |
