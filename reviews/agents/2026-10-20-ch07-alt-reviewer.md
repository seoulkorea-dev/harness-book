# ch07 그림 시안 alt-reviewer(2026-10-20, PR #40)

## 선택
- 그림 7-1: 시안 A(흐름형)를 고릅니다. 이유는 세 가지입니다.
  - 산출물 → 방법 선택 → 판정 → 통과/미통과의 순서가 위에서 아래로 한 번에 읽힙니다.
  - 세 방법 카드가 한 상자 안에 나란히 있어 "셋 중 하나"로 읽힙니다.
  - 판정이 별도 상자로 있고, 완료 보고가 연결 없이 바깥에 있습니다.
  - 시안 B는 세 카드가 세로로 쌓이고 화살표가 맨 위 카드(자동 검사)만 가리켜, 직렬 통과(깔때기)나 "자동 검사로 고정"으로 읽힙니다. 이는 명세의 "쓰지 않을 것"과 부딪힙니다. 또 산출물이 없고 판정이 상자가 아니며 출력 원문 화살표가 없습니다.
  - B의 "판정 밖" 회색 영역은 장점이므로 A에 가져오면 좋습니다(발견 4).
- 그림 7-2: 시안 A(가로 흐름, 입력 묶음)를 고릅니다. 이유는 두 가지입니다.
  - 결과, 기준표, 예시 답안이 "입력" 영역으로 묶여 "함께 입력"이 보이고, 채점 → 판정값 → 통과 조건이 각각 상자로 나뉩니다. 명세의 구성 요소 일곱 개가 모두 별도 상자입니다.
  - 시안 B는 입력 세 개가 한 줄 글로 합쳐졌습니다. 통과 조건은 단계 제목 속에 들어가 상자가 아닙니다. 다시 작업이 맨 위(1단계 옆)에 있고, 점선이 그림 전체를 아래에서 위로 가로질러 "시작으로 돌아가는 것"처럼 읽힙니다.
  - B의 번호는 순서를 분명히 하지만 A도 왼쪽에서 오른쪽, 아래로 읽는 흐름이라 번호가 없어도 순서가 읽힙니다.
