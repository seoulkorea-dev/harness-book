# 논지 사슬 표(reviews/flow/)

장마다 장 전체의 흐름을 한 장의 표로 보여 주는 자료입니다(D-117, 이슈 #31). 작가가 장 전체를 읽지 않고도 흐름을 점검할 수 있게 하고, 장 PR 설명에 링크합니다.

- 만드는 주체: flow-reviewer가 장 전체를 통독해 문안을 만들고, 메인 세션이 `<장>-flow.md`(예: ch04-flow.md)로 저장합니다.
- 갱신: 장을 고친 뒤 다시 점검하면 같은 파일을 덮어쓰고 날짜를 바꿉니다. 병합할 때는 끊긴 곳이 0이어야 합니다.
- 판정: 사슬이 끊긴 곳(앞 절과의 연결을 쓰지 못하는 절, 주장을 한 줄로 쓰지 못하는 절)은 editor가 필수로 판정합니다.

## 형식
```
# <장> 논지 사슬(YYYY-MM-DD)
장의 주장: <주장 줄>

| 절 | 이 절의 주장 한 줄 | 앞 절과의 연결(왜 여기 있나) | 근거 | 막히는 곳 |
|---|---|---|---|---|
```
