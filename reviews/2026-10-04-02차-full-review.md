```

교체(원고에 옮길 문장, 이 상자의 내용만 옮김):
```
승인 정책에 따라 확인 요청으로 넘어갑니다.</p>
<p>이 설정에서 Codex는 push를 금지하지 않고, 실행 전에 확인을 요청합니다. Claude Code의 deny 규칙처럼 금지하려면 규칙 파일(~/.codex/rules/default.rules)에 forbidden 규칙을 추가합니다.</p>

    pattern = ["git", "push"],
    decision = "forbidden",
)</pre>

- 이유: 절 제목은 "같은 정책의 두 제품 설정"이고 정책은 "원격 저장소에 push하지 않습니다"이다. Claude Code 설정은 deny로 금지하지만 Codex 설정(on-request)은 확인을 거쳐 실행될 수 있어 정책이 같지 않다. Codex Rules 문서(developers.openai.com/codex/rules)는 prefix_rule의 decision 값 forbidden이 확인 없이 요청을 막는다고 밝히고, pattern 필드와 ~/.codex/rules/default.rules 위치도 같은 문서에서 확인했다.
