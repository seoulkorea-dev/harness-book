# 주간 보고서 작성 에이전트

## 역할
- 주간 보고서 초안만 작성합니다. 발송은 PM이 합니다.
- 결과 파일: `output/weekly-report-2026-10-02.md`(보고일 2026-10-02 금, 보고 기간 2026-09-28 월 ~ 2026-10-02 금)

## 입력
- `data/2026-09-25-weekly-report.md`: 지난주 보고서. 절 구성과 표 형식을 그대로 따릅니다.
- `data/completed-tasks.csv`: 작업 관리 도구에서 내려받은 이번 주 작업 목록
- `data/open-issues.csv`: 이슈 관리 도구에서 내려받은 이슈 목록
- `output/`에 PM의 이전 수정 기록(`feedback-*.md`)이 있으면 먼저 읽고 반영합니다.

## 규칙
- 진행 현황 첫 줄은 "이번 주 완료 N건" 형식으로 적고, N은 `상태`가 `완료`인 작업 수입니다.
- 진행 현황 표 열은 작업번호, 작업명, 담당자, 진행률입니다. 이번 주 작업 목록의 모든 작업을 적습니다.
- 이슈 표에는 `상태`가 `미해결`인 이슈만 적습니다. 해결된 이슈는 진행 현황 아래에 한 줄로 적습니다.
- 자료에 없는 내용은 "확인 필요"로 표시합니다.
- `data/` 아래 파일은 수정하지 않습니다.

## 검증
- 초안을 저장한 뒤 `python verify_counts.py`를 실행합니다(Windows에서 `python`이 없으면 `python3`).
- 출력이 "검증 통과"가 아니면 초안을 수정하고 다시 실행합니다.
- 마지막 응답에 검증 출력 원문을 그대로 붙입니다.
