# Chapter 2 예제 실행 절차 (변경 요청 영향 검토)

1. claude.ai에서 임시 채팅(incognito)을 열고 모델 이름을 기록합니다.
2. `1-before.txt` 내용을 그대로 붙여 넣고 실행합니다. 출력 전체를 `output-1-before.md`로 저장합니다.
3. 새 임시 채팅에서 같은 모델로 `2-after.txt` 내용을 실행합니다. 출력 전체를 `output-2-after.md`로 저장합니다.
4. 두 출력 파일과 모델 이름을 작성 채팅에 전달합니다. 원고의 "예상 결과"는 출력 원문에 맞춰 "실행 결과"로 수정합니다(D-024).
