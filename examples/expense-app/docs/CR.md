# CR 정산 요청 화면에 프로젝트 코드 선택 항목 추가

- 요청 부서: 재무팀
- 요청일: 2026-10-05
- 사유: 프로젝트별 경비 집계를 월말 결산에 반영하기 위함
- 결정: D-012(조건부 수용, 프로젝트 코드는 인사 시스템 일 1회 갱신 자료 data/projects.csv 사용)

## 수용 기준
1. 등록 화면에서 프로젝트 코드 목록의 코드를 선택할 수 있다(입력 이름 project_code).
2. 목록에 없는 코드로 등록하면 거부하고, 거부 사유에 입력한 코드를 표시한다.
3. 목록 화면에 프로젝트 코드를 표시한다.
4. 프로젝트 코드가 없는 기존 요청도 목록에 그대로 표시한다.
5. data/projects.csv는 변경하지 않는다.

수용 기준은 acceptance/test_cr07.py로 시험한다.
