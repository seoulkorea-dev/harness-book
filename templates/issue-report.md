# 이슈 보고 형식(작가 지시 2026-10-20)

작가 요청 이슈의 "작업 시작" 댓글과 결과 댓글(닫을 때)은 이 형식으로 씁니다. 장(Chapter) 단위로 나누어 씁니다. 바꾸지 않은 장은 진행 표에만 두고 상세 절에는 쓰지 않습니다.

## 작업 시작 댓글
```
작업 시작
- 대상 chapter: Chapter 2, Chapter 3(그림만)
- 브랜치와 초안 PR: <브랜치>, #<번호>
```

## 결과 댓글
```
## 결과
- PR: #<번호> <주소>(editor 결론, CI, 병합 여부)
- 작가 확인 추가: Q-<번호>(없으면 "없음")

## 진행 완료 chapter
| chapter | 상태 | 이번 작업 | 관련 PR |
|---|---|---|---|
| 시작하며 | 대기 | | |
| Chapter 1 | 완료(기준) | | #5, #6 |
| Chapter 2 | 완료 | 수정 | #7, #14, #15 |
| ... | | | |
| 마치며, 부록 | 대기 | | |

상태: 완료(개정을 마치고 병합), 진행 중, 대기(개정 전). 이번 작업 열에는 이번에 바꾼 장만 "수정"으로 표시합니다.

## chapter별 작업 내용과 수정 내용
### Chapter N 제목
- 작업 내용: 무엇을 왜 했는지 한두 줄(이슈 항목 번호, 결정 번호)
- 수정 내용: 절, 표, 그림 단위로 바뀐 것
  - 절 "<절 이름>": <바뀐 문장 요지>
  - 표 N-n: <바뀐 행이나 열>
  - 그림 N-n: <바뀐 구성>
- 반영하지 않은 것: <보류한 의견과 이유>(없으면 생략)

### 장 밖의 변경(설정, 규칙 문서 등)
- <파일>: <바뀐 것>
```
